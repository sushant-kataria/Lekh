# About Lekh

**Lekh** (लेख) means "a piece of writing" in Hindi and Sanskrit. It was
created by **Sushant Kataria** to answer one question: what if code were as
easy to read as a sentence, but as safe as Rust?

Lekh keeps the ideas that make Rust programs reliable (one owner for every
value, no null, errors as values, no data races) and says them in plain words:
`lend`, `give`, `maybe`, `result`, `at the same time`. The checker explains
every mistake in English and shows a fix.

Lekh 0.2 is a working prototype written in Python, with no dependencies. It's
good for learning, scripts, command-line tools and data tasks. The roadmap
below says honestly what is done and what isn't.

## This website is a Lekh program

Every page here was generated by [`site/build.lekh`](../site/build.lekh), a
static-site generator written in Lekh. It reads the Markdown docs, converts
them to HTML with a Markdown converter written in Lekh
([`site/lib/markdown.lekh`](../site/lib/markdown.lekh)), colours the code with a
highlighter written in Lekh, and runs the example programs to capture their
real output. Then [`site/check_links.lekh`](../site/check_links.lekh) checks
every link.
