# Assets

- `lekh-banner.svg` is drawn by the Lekh program [`site/banner.lekh`](../site/banner.lekh);
  `lekh-banner.png` (1280x640, also the GitHub social preview) is rendered from it with
  `python3 tools/render_banner.py`.
- `fonts/` holds the two open fonts the banner uses, under the SIL Open Font License 1.1:
  [Inter](https://github.com/rsms/inter) (`fonts/Inter-OFL.txt`) and
  [JetBrains Mono](https://github.com/JetBrains/JetBrainsMono) (`fonts/JetBrainsMono-OFL.txt`).
